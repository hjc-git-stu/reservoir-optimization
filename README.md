# Reservoir Optimization（油藏优化/水资源调度）

调度水资源与优化算法研究（DP / 多目标优化）

## 目录
- `src/dp/`: 动态规划（Yeh 1985 复现）
- `src/nsg2/`: 多目标优化（Labadie 2004 关联）
- `data/`: 水文/库容数据（小文件，大文件用 Zotero/云盘）
- `outputs/`: 运行结果（被 .gitignore 忽略大文件）
- `figures/`: 论文配图
- `reading_notes/`: Obsidian 笔记 + Zotero bib（知识库）

## 环境
- Python 3.9+ / LaTeX / Overleaf
- Zotero + Better BibTeX + Obsidian Citations
